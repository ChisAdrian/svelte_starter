🚀 Complete Guide: Start a New Svelte Project

JavaScript + VS Code Setup + Single File Plugin - Zero TypeScript Hassle

📋 Prerequisites:
  • Node.js (version 18 or higher) installed
  • VS Code installed
  • Basic knowledge of terminal/command line

Step 1: Create the Svelte Project

Open your terminal and run:

npm create vite@latest my-app -- --template svelte

Replace my-app with your project name (e.g., my-project, dashboard-app, etc.)

Then navigate into your project folder:

cd my-app

Install dependencies:

npm install

Step 2: Configure VS Code for JavaScript (No TypeScript Errors)

2.1 Install the Svelte Extension

  1. Open VS Code
  2. Go to Extensions (Ctrl+Shift+X or Cmd+Shift+X)
  3. Search for "Svelte for VS Code" (svelte.svelte-vscode)
  4. Click Install

2.2 Create jsconfig.json (Stops TypeScript Errors)

In your project root folder, create a file called jsconfig.json and paste this:

{
  "compilerOptions": {
    "checkJs": false,
    "strict": false
  },
  "exclude": ["node_modules", "dist", "build"]
}

2.3 Configure Auto-Formatting

Create a .vscode folder in your project root, then inside it create settings.json:

{
  "[svelte]": {
    "editor.defaultFormatter": "svelte.svelte-vscode"
  },
  "editor.formatOnSave": true
}

2.4 Restart VS Code's Language Server

  1. Press Ctrl+Shift+P (or Cmd+Shift+P on Mac)
  2. Type "TypeScript: Restart TS server"
  3. Press Enter

Step 3: Test Your Setup

3.1 Start the Development Server

npm run dev

3.2 Open in Browser

  • Click the link shown in terminal (usually http://localhost:5173)
  • You should see the Svelte welcome page

3.3 Edit a Component

Open src/App.svelte and replace its content:

<script>
  // Pure JavaScript - no types needed!
  let count = 0;
  
  function handleClick() {
    count += 1;
  }
</script>

<main>
  <h1>Hello Svelte!</h1>
  <p>Count: {count}</p>
  <button on:click={handleClick}>
    Click me
  </button>
</main>

<style>
  main {
    text-align: center;
    padding: 2rem;
  }
  
  button {
    background: #ff3e00;
    color: white;
    border: none;
    padding: 0.5rem 1rem;
    border-radius: 4px;
    cursor: pointer;
    font-size: 1rem;
  }
  
  button:hover {
    background: #ff5e00;
  }
</style>

Save the file (Ctrl+S) and watch the browser update automatically! ✨

🎁 Bonus: Create a Single HTML File with vite-plugin-singlefile

✨ What is it? A Vite plugin that bundles your entire Svelte app into ONE HTML file — all CSS and JavaScript inlined!

Why Use It?

  • 📧 Share demos as a single file attachment
  • 🎯 Embed apps in other platforms easily
  • 📦 Portable widgets that work anywhere
  • 🚀 No server needed — just double-click the HTML file

Step 1: Install the Plugin

npm install --save-dev vite-plugin-singlefile

Step 2: Configure vite.config.js

Replace your existing vite.config.js with this:

import { defineConfig } from 'vite';
import { svelte } from '@sveltejs/vite-plugin-svelte';
import { viteSingleFile } from 'vite-plugin-singlefile';

export default defineConfig(({ command }) => ({
  plugins: [
    svelte(),
    // Only use singlefile plugin during build (not development)
    command === 'build' && viteSingleFile({
      removeViteModuleLoader: true  // Removes Vite's module loader for cleaner output
    })
  ],
  build: {
    minify: true,  // Minifies the output (smaller file size)
    cssCodeSplit: false,  // Keeps CSS in the same file
    assetsInlineLimit: 100000000  // Inlines all assets
  }
}));

Step 3: Build Your Single File

npm run build

Your output will be in dist/index.html — a single, self-contained HTML file.

Comparison: Before vs After

Without Plugin (npm run build) With Plugin (npm run build)
Multiple files (HTML + CSS + JS chunks) One HTML file ✨
Needs a web server to run Open directly in browser 🚀
Complex deployment Send via email or chat 📧
💡 Perfect Use Cases:
  • Interactive resume or portfolio piece
  • Small utility app (calculator, todo list, timer)
  • Demo for a client or job interview
  • Embedding in a CMS or documentation site
⚠️ Important Notes:
  • removeViteModuleLoader: true makes your file smaller and cleaner
  • Works best for small to medium apps — large apps create massive HTML files
  • Development mode (npm run dev) still runs normally with hot reload
  • The single-file behavior only applies to npm run build

❗ Common Issues & Fixes

"Cannot find module 'xxx'"
Run npm install again or restart the dev server with npm run dev
Svelte file shows as plain text
  1. Click bottom-right corner of VS Code
  2. Click on language mode (might say "HTML")
  3. Select "Svelte" from dropdown
  4. Choose "Always use Svelte"
Still getting TypeScript errors?
  • Make sure jsconfig.json exists in your project root
  • Run "TypeScript: Restart TS server" from command palette
  • Close and reopen VS Code
Port 5173 already in use
Run this instead: 
npm run dev -- --port 3000
Build output is too large?
The single file plugin works best for small apps. For larger apps, consider:
  • Removing vite-plugin-singlefile for production builds
  • Using code splitting (remove the plugin)
  • Lazy loading heavy components
💡 Why Choose Svelte (without SvelteKit)?
  • Best for: Simple SPAs, component libraries, prototypes, single-file demos
  • Routing: You manage it (e.g., with svelte-navigator)
  • Bundle Size: Smaller for simple apps
  • Learning Curve: Easier to start with pure Svelte first
  • Single File Output: Perfect for sharing demos
